# 栖止 · Qizhi

> **实验产品，非最终版本。**
>
> 这是一个仍在开发中的 Android 休息与睡眠守护实验。功能、交互、数据格式和系统行为都可能随时调整，不保证稳定，也不适合用于医疗、看护或任何关键场景。请只用它做个人实验。

栖止是一款通过 **Shizuku** 获得高阶系统能力的 Android 应用：它把睡眠、专注和休息变成可执行的边界，在需要的时候收起让你分心的应用。

- 完全离线：**没有 INTERNET 权限**，没有账号，没有统计上报。
- 系统应用、电话、紧急呼叫和设置永不被阻断。
- 休息 / 睡眠守护需要通过设备锁屏验证才能提前结束，避免把自己锁在门外。

## 功能

- **睡眠窗口**：设置入睡、起床与睡前缓冲，到点进入睡眠守护。
- **强制休息**：专注结束后进入全屏休息界面，包含呼吸引导、倒计时与安静的视觉。
- **应用管控**：按应用设置「专注 / 休息 / 睡眠」阻断，以及每日使用限额。
- **Shizuku 特权**：勿扰、夜间灰度、熄屏、强制停止、精确闹钟、使用情况访问与悬浮窗的一键配置。
- **无障碍增强**：识别前台应用，在打开被管控应用时立即返回桌面。
- **深浅色模式**：跟随系统、浅色、深色三档，全部使用同一套自绘主题。
- **本地统计**：专注分钟、休息次数、睡眠守护时长、连续守护天数与近七日柱状图。
- **安全退出**：长按 6 秒 + 设备锁屏验证；设备未设置锁屏时使用 8 秒长按确认。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| Shizuku / Root | 执行 shell 级系统操作，如强制停止、勿扰、灰度、熄屏 |
| 使用情况访问 | 读取今日应用使用时长与当前前台应用 |
| 悬浮窗 | 显示休息 / 睡眠全屏守护界面 |
| 无障碍服务 | 应用切换时即时识别并执行管控；不读取屏幕内容 |
| 精确闹钟 | 准点触发睡眠、起床与阶段结束 |
| 通知 | 守护状态、睡前提醒与完成总结 |
| 电池优化白名单 | 避免夜间守护被系统中断 |

栖止不会删除应用数据、不会修改锁屏密码、不会禁用系统应用，也不会拦截电话和紧急呼叫。

## 构建

要求：

- JDK 17
- Android SDK Platform 35
- Build Tools 35.0.0
- Gradle 8.10.2

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
gradle :app:testDebugUnitTest :app:assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/`。

仓库包含 GitHub Actions 工作流，每次 push 到 `main` 或手动触发都会构建 debug APK，并上传为 artifact。

## 结构

```text
app/src/main/java/com/qizhi/rest/
  core/       时间窗口、阻断策略与纯 Kotlin 逻辑
  data/       设置、规则、历史、会话与使用情况
  privilege/  Shizuku / Root 执行器与权限工具
  guard/      守护服务、无障碍、悬浮窗、闹钟与通知
  ui/         Compose 主题、组件与页面
```

## 已知限制

- 不同厂商的 ROM 对后台、精确闹钟、无障碍和 Shizuku 的限制不同。
- 勿扰与灰度依赖系统设置接口，部分设备可能无法恢复原来的值；应用会在下次启动时重试恢复。
- 系统应用不参与管控；这是安全边界，不是遗漏。
- 这是一个实验项目，不提供睡眠诊断或治疗建议。
